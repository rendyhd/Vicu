## In short

- **Keys are written for Windows and Linux.** On a Mac, use <kbd>Cmd</kbd> where this page says <kbd>Ctrl</kbd>, and <kbd>Option</kbd> where it says <kbd>Alt</kbd>.
- **Three shortcuts can be changed:** Quick Entry, Quick View and the voice shortcut, in **Settings**. The rest are fixed.
- **The two shortcuts that work in any app** are Quick Entry and Quick View, after you turn them on.
- **A shortcut that does nothing** is usually in the wrong place. For example, the list shortcuts need the list to have focus, and the Pro shortcuts need Pro to be on.
- **Settings, Keyboard Shortcuts** shows the main shortcuts inside the app.

## Shortcuts you can change {desktop}

| Shortcut | Default | Where to change it |
|---|---|---|
| Quick Entry | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>, or <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> on a Mac | **Settings, Quick Entry / View**. Click the hotkey and press the new one. |
| Quick View | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd>, or <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> on a Mac | **Settings, Quick Entry / View** |
| Voice input | None. It stays off until you record one. | **Settings, Keyboard Shortcuts, Voice input**. It works only while Vicu is in front. |

Both Quick shortcuts work from any app and must be turned on first. See [On the desktop](guide:desktop).

## Everywhere in the app

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | Open the command palette |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Go to Quick find |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New task (**File, New task**) |
| <kbd>Ctrl</kbd>+<kbd>J</kbd> | Show or hide Ask |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Show or hide comments |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Print the list (**File, Print**) |
| <kbd>F5</kbd> or <kbd>Ctrl</kbd>+<kbd>R</kbd> | Refresh from the server (**View, Refresh**) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | Reload the window (**View, Reload window**) |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Open Settings (macOS app menu) |

The **View** menu also has zoom in, zoom out, reset zoom and full screen.

## Moving through a list

| Keys | What it does |
|---|---|
| <kbd>Up</kbd> and <kbd>Down</kbd> | Previous and next task |
| <kbd>Enter</kbd> | Open the task |
| <kbd>Esc</kbd> | Close the task, clear focus, or clear the selection |
| <kbd>Space</kbd> | Complete the focused task and move to the next |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all tasks |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete the selected tasks. It asks first if **Confirm before deleting** is on. |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Up</kbd> or <kbd>Down</kbd> | Move the task up or down (a manual order, or among tasks without a date) |

## Working on tasks

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Complete the selected task. In an open task, complete and close it. |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | Set the due date to today |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate the selected tasks |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the selected tasks' titles |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Make tasks from the clipboard, one task per line |
| <kbd>!</kbd> | Due today. Type it in a title, or on a list. |

## In an open task

| Keys | What it does |
|---|---|
| <kbd>Enter</kbd> (in the title) | Move to the notes |
| <kbd>Esc</kbd> | Save and close |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Save and close |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Complete and close |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Show or hide comments |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> (in notes) | Paste without turning Markdown into formatting |
| <kbd>Alt</kbd>+<kbd>Up</kbd> or <kbd>Down</kbd> (in a notes list) | Move the line up or down |
| <kbd>Left</kbd> and <kbd>Right</kbd> (image viewer) | Previous and next image |

## Projects in the sidebar

| Keys | What it does |
|---|---|
| <kbd>F2</kbd> | Rename the focused project |
| <kbd>Shift</kbd>+<kbd>F10</kbd> or the Menu key | Open its menu |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+arrow keys | Move the project up or down, into the one above, or out one level |

## Plan

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New task at the day's next free time |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | New event |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Up</kbd> or <kbd>Down</kbd> | Move a block or your event 15 minutes earlier or later |

## Guided sessions

In a card session such as **Sort the Inbox**:

| Keys | What it does |
|---|---|
| <kbd>Enter</kbd> or <kbd>Right</kbd> | Next. Saves the card's choices. |
| <kbd>Left</kbd> | Back |
| <kbd>S</kbd> | Skip |
| <kbd>1</kbd> to <kbd>4</kbd> | The quick dates: Today, Tomorrow, This weekend, Next week |
| <kbd>D</kbd> | Pick a date |
| <kbd>0</kbd> | No date |
| <kbd>P</kbd> | Pick a project |
| <kbd>E</kbd> or <kbd>F2</kbd> | Edit the title |
| <kbd>C</kbd> | Complete |
| <kbd>Delete</kbd> | Delete |
| <kbd>Esc</kbd> | Leave the session |

On a project review page, <kbd>R</kbd> marks the project reviewed and <kbd>S</kbd> skips it. See [Review and guided organizing](guide:review).

## Quick Entry and Quick View

These keys work inside their small windows.

| Keys | What it does |
|---|---|
| <kbd>Enter</kbd> (Quick Entry) | Save the task |
| <kbd>Tab</kbd> (Quick Entry) | Add a description |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> (Quick Entry) | Link the browser tab or Obsidian note |
| <kbd>Ctrl</kbd>+<kbd>Left</kbd> or <kbd>Right</kbd> (Quick Entry) | Switch project. The modifier is a setting. |
| <kbd>Up</kbd>, <kbd>Down</kbd>, <kbd>Enter</kbd> (Quick View) | Move, and complete the selected task |
| <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Enter</kbd>, <kbd>!</kbd> (Quick View) | Show the description, edit, set due today |
| <kbd>Esc</kbd> | Close the window |

## Pro {pro}

These work only while [Pro](guide:pro) is on.

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | Flag or unflag the selected tasks |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Focus on some projects |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> | Import meeting notes |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Open the inspector for two or more selected tasks |
| <kbd>1</kbd> to <kbd>6</kbd> on a promise row | Delivered, Late, Not yet, New date, Dropped, Ask me tomorrow |
| <kbd>Enter</kbd>, <kbd>S</kbd>, <kbd>A</kbd> in a meeting round | Next person, skip, absent |

<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> stays the developer tools. See [Promises and people](guide:pro/promises) and [Power tools](guide:pro/power).
