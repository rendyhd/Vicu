# Vicu 1.5.0 Release + macOS Signing/Notarization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a stable Vicu 1.5.0 (consolidating five betas) whose macOS DMG is Developer ID–signed and Apple-notarized, removing the unsigned-app workaround.

**Architecture:** Enable electron-builder's built-in notarization (`mac.notarize: true`, bundled `@electron/notarize` + `notarytool`) and wire the release workflow's `build-macos` job to import a Developer ID cert and pass Apple credentials — mirroring the proven cert-import scaffolding already in `build-macos.yml`. Signing is conditional on a secret being present, so a missing secret degrades to unsigned rather than hard-failing CI. A manual `workflow_dispatch` run of `build-macos.yml` verifies the signed+notarized DMG before the `v1.5.0` tag is pushed.

**Tech Stack:** electron-builder 25, GitHub Actions, macOS `notarytool`/`security` keychain tooling, `gh` CLI.

**Branch:** `release/1.5.0-mac-signing` (already created; spec committed here).

### Task 3: 🤖 Sign + notarize in the release workflow

**Files:**
- Modify: `.github/workflows/release.yml:61-88` (the `build-macos` job)

- [ ] **Step 1: Replace the `build-macos` job body**

Replace the current job (from `build-macos:` through its `Remove blockmap assets` step) with:

```yaml
  build-macos:
    needs: create-release
    runs-on: macos-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm

      # Import the Developer ID cert into a temporary keychain when the secret
      # is present. Mirrors build-macos.yml. If BUILD_CERTIFICATE_BASE64 is unset
      # this step is skipped and the build falls back to an unsigned app.
      - name: Import signing certificate
        if: env.BUILD_CERTIFICATE_BASE64 != ''
        env:
          BUILD_CERTIFICATE_BASE64: ${{ secrets.BUILD_CERTIFICATE_BASE64 }}
          P12_PASSWORD: ${{ secrets.P12_PASSWORD }}
          KEYCHAIN_PASSWORD: ${{ secrets.KEYCHAIN_PASSWORD }}
        run: |
          CERTIFICATE_PATH=$RUNNER_TEMP/build_certificate.p12
          KEYCHAIN_PATH=$RUNNER_TEMP/app-signing.keychain-db

          echo -n "$BUILD_CERTIFICATE_BASE64" | base64 --decode -o $CERTIFICATE_PATH

          security create-keychain -p "$KEYCHAIN_PASSWORD" $KEYCHAIN_PATH
          security set-keychain-settings -lut 21600 $KEYCHAIN_PATH
          security unlock-keychain -p "$KEYCHAIN_PASSWORD" $KEYCHAIN_PATH

          security import $CERTIFICATE_PATH -P "$P12_PASSWORD" -A -t cert -f pkcs12 -k $KEYCHAIN_PATH
          security set-key-partition-list -S apple-tool:,apple: -k "$KEYCHAIN_PASSWORD" $KEYCHAIN_PATH
          security list-keychain -d user -s $KEYCHAIN_PATH

      - run: npm ci

      # Sign only if the cert secret is present (CSC_IDENTITY_AUTO_DISCOVERY
      # true), otherwise produce an unsigned build instead of failing. The
      # APPLE_* vars drive notarytool; electron-builder skips notarization when
      # the app is unsigned.
      - name: Build and publish
        run: npm run dist:mac:publish
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          CSC_IDENTITY_AUTO_DISCOVERY: ${{ secrets.BUILD_CERTIFICATE_BASE64 != '' && 'true' || 'false' }}
          APPLE_ID: ${{ secrets.APPLE_ID }}
          APPLE_APP_SPECIFIC_PASSWORD: ${{ secrets.APPLE_APP_SPECIFIC_PASSWORD }}
          APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}

      - name: Cleanup keychain
        if: always()
        run: |
          if [ -f "$RUNNER_TEMP/app-signing.keychain-db" ]; then
            security delete-keychain $RUNNER_TEMP/app-signing.keychain-db
          fi

      - name: Remove blockmap assets
        run: |
          for asset in dist/*.blockmap; do
            name=$(basename "$asset")
            gh release delete-asset "${{ github.ref_name }}" "$name" --yes || true
          done
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Key differences from the old job: added "Import signing certificate" (before `npm ci`), changed `CSC_IDENTITY_AUTO_DISCOVERY` from hardcoded `false` to the conditional expression, added the three `APPLE_*` env vars, and added "Cleanup keychain". The `Remove blockmap assets` step is unchanged.

### Task 6: 🧑 Create the Developer ID cert, notarization credential, and GitHub secrets

> **Blocking manual gate.** Done by the user on the Mac signed in to the Apple Developer account. The agent cannot perform these steps.

- [ ] **Step 1: Create + export the Developer ID Application certificate**
  - Xcode → **Settings → Accounts** → select the team → **Manage Certificates → + → Developer ID Application**. (Or developer.apple.com → Certificates → **+** → *Developer ID Application*, uploading a CSR from Keychain Access → *Certificate Assistant → Request a Certificate from a Certificate Authority*.)
  - **Must be "Developer ID Application"** — not "Apple Development" or "Mac App Distribution", or Gatekeeper will still block direct downloads.
  - In **Keychain Access**, right-click the new "Developer ID Application: … (TEAMID)" cert → **Export** → save `cert.p12` with a password (→ `P12_PASSWORD`).
  - Base64-encode: `base64 -i cert.p12 | pbcopy` (→ `BUILD_CERTIFICATE_BASE64`).

- [ ] **Step 2: Create an app-specific password**
  - appleid.apple.com → **Sign-In and Security → App-Specific Passwords → +** → name it "Vicu notarization" → copy `xxxx-xxxx-xxxx-xxxx` (→ `APPLE_APP_SPECIFIC_PASSWORD`).

- [ ] **Step 3: Note the Team ID**
  - developer.apple.com → **Membership** → 10-char **Team ID** (→ `APPLE_TEAM_ID`).

- [ ] **Step 4: Add the GitHub repository secrets**
  - GitHub → repo **Settings → Secrets and variables → Actions → New repository secret**, add all six:

  | Secret | Value |
  |---|---|
  | `BUILD_CERTIFICATE_BASE64` | base64 of `cert.p12` |
  | `P12_PASSWORD` | the `.p12` export password |
  | `KEYCHAIN_PASSWORD` | any random string |
  | `APPLE_ID` | Apple ID email |
  | `APPLE_APP_SPECIFIC_PASSWORD` | app-specific password from Step 2 |
  | `APPLE_TEAM_ID` | 10-char Team ID from Step 3 |

## Notes / Risks

- **Windows dev box:** Mac signing/notarization cannot be tested locally; Task 7's CI run is the real verification. All other local checks are YAML/version sanity only.
- **Never hard-fails on a missing secret:** `CSC_IDENTITY_AUTO_DISCOVERY` falls back to `false` (unsigned) and electron-builder skips notarization for unsigned apps.
- **Line endings (Windows):** edits to `.yml`/`.md`/`package.json` should stay LF; `.gitattributes` normalizes, but avoid tools that rewrite whole files to CRLF.
