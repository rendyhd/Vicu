# Vicu 2.6.2

Vicu 2.6.2 lets you duplicate tasks and assign people to several tasks at once. Today keeps its routine section short, projects and lists can go without an icon, and you can play the completion sound from Settings. Update the phone app to 2.6.2 at the same time: it has the same changes.

If you find a rough edge, please [open an issue](https://github.com/rendyhd/vicu/issues).

### New

- **Duplicate a task.** **Duplicate task** is in a task's context menu and in the open task's More menu, and Ctrl+D (Cmd+D on a Mac) duplicates the selected tasks. The copy is a new open task in the same project with the title, notes, dates, priority, repeat, reminders, labels, assignees and subtasks. Offline, the copy is made without its subtasks, and Vicu says so. Copy task (Ctrl+C) still copies only the titles.
- **Assign several tasks at once.** When every selected task is in a shared project, the selection bar and the context menu have **Assign**. A person assigned to all of them is ticked, to some of them partly ticked; pick someone to assign them to every selected task, or a ticked person to take them off all of them.
- **A shorter routine section on Today.** Today shows one row per routine, at its next time, with how far you are (such as 1/3) for a routine with several times. Only the routines due within two hours, or still open from earlier, show: two by default, the rest behind one line such as "2 later today". The Routines header folds the section. Choose how many show in Settings, Routines, **Routines shown on Today**.
- **No icon.** Edit Project has **Folder** or **None**, and a custom list's icon picker has **None**, for names that start with an emoji. With None the name starts where the icon would be. The choice syncs to the phone app.
- **Play the completion sound.** The completion sound's Test button is now **Play**. It plays the sound from the start, and a file that cannot be played says so.

### Fixes

- **Assistant addresses.** Switching provider no longer wipes the address you typed for Other: each provider keeps its address and models. Other, Ollama and Open WebUI keep up to five saved addresses, each with its own models and key, and **Add address** saves another one. The address field says that the version path (such as /v1) is needed, and an error from an address without one says it may be missing.
- **Assistant keys.** Each provider now keeps its own key, and each saved address of Other, Ollama and Open WebUI its own, so a key only goes to the address it was saved for. The key you had before moves to the provider you were using.
