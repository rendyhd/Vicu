# Vicu 1.10.1

Vicu 1.10.1 ships together with Vicu Android 1.10.1. You can now manage projects right from the sidebar, and projects have their own tab in Settings.

This is a pre-release that builds on 1.10.0; if you are coming from 1.8, read the [1.9.0](https://github.com/rendyhd/vicu/releases/tag/v1.9.0) and [1.10.0](https://github.com/rendyhd/vicu/releases/tag/v1.10.0) notes too. If you find a rough edge, please [open an issue](https://github.com/rendyhd/vicu/issues).

### Manage projects from the sidebar

- Every project has one menu. Point at a project in the sidebar and click **…**, or right-click it; the same menu is in the project's page header and in Settings. It has **Rename**, **Edit…**, **Add subproject**, **Move to…**, **Set as Inbox**, **Review** (mark reviewed, review cadence, exclude from or include in review), **Archive** and **Delete**.
- Drag a project onto another to put it inside, or towards the top or bottom edge of a row to place it before or after. Drop it on the **Projects** header to make it a top-level project. Moving a project to another parent shows a message with **Undo**.
- With the keyboard: F2 renames the focused project, Shift+F10 opens its menu, and Alt+Shift with the arrow keys moves it up, down, into the project above or out one level.
- The **+** next to Projects adds a project right in the sidebar: type its name and press Enter. Renaming happens in place too.
- Archived projects are listed in a collapsed **Archived** group below your projects, with **Restore**. An archived project's page has a **Restore project** button.
- One dialog edits a project's name, parent and colour.
- Projects can no longer be put inside the Inbox. The sidebar does not show the Inbox, so they would disappear from the tree.

### Settings

- A new **Projects** tab holds the Inbox choice, all your projects (click one to edit it, drag to rearrange, **…** for the rest), the archived projects, display options and project review.
- Project review lists the projects you excluded from review, each with **Include again**.
- New setting **Show project progress in the sidebar** (on by default, under Projects, Display): turn it off to hide the progress rings.
- **General** has a new **Appearance** section with the theme and the clock.
- Every Settings tab has the same width.

### Fixes

- A completed task no longer jumps to the end of its group when a background refresh runs during the 5 second hold. It stays where it was until it collapses.
- Message text lines up with its icon and buttons, and the default review cadence field lines up with its label.

### Upgrade notes

- The Inbox choice and project review moved from **General** to the new **Projects** tab. Your settings carry over.
- Update both apps to 1.10.1 to get the same project actions on both.
