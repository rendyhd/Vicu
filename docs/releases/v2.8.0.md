# Vicu 2.8.0

**Supporting Vicu.** A couple of you have asked how you can support Vicu, so there is now a page for it: [ko-fi.com/rendyhd](https://ko-fi.com/rendyhd). I build Vicu in my evenings, next to a full-time job and a young family. I made it because I wanted it myself, and I still use it every day. There are no ads, no Vicu account and nothing behind a paywall, and that won't change. I truly appreciate the gesture: every tip, big or small, tells me this work matters to someone. Thank you.

Vicu 2.8.0 brings Vikunja's saved filters into Vicu, turns Markdown into formatted notes, keeps files you add offline, and makes it easier to move a plan to another day. Linux AppImages can now update themselves, and an update no longer unpins Vicu on Windows. Update the phone app to 2.8.0 too, so both apps read saved filters, list rules and planner moves the same way.

If you find a rough edge, please [open an issue](https://github.com/rendyhd/vicu/issues).

### New

- **Saved filters.** Vikunja's saved filters showed up as empty projects. They now become custom lists: Vicu imports every saved filter it can read the first time it syncs your lists, and Settings, Projects, Saved filters offers new ones and has **Import saved filters**. An import is a copy, which the list says once, and two devices never import the same filter twice. ([Vicu-Mobile#103](https://github.com/rendyhd/Vicu-Mobile/issues/103))
- **Rules in custom lists.** A custom list can have a rule in Vikunja's filter syntax, such as `done = false && priority > 2`, next to its other conditions, and Quick View and Ask follow it too. The editor shows label and project names, suggests as you type, and keeps Save off until the rule reads.
- **Then by.** A custom list can sort by a second field, and the orders are named for the field, such as "Soonest first" and "A to Z".
- **Markdown in notes.** Markdown you paste into the notes becomes formatting, so a pasted `[text](url)` is a link. Typing Markdown formats as you go: headings, quotes, lists, `[ ]` checklists, dividers, bold, italic, strikethrough, code and links. Notes are still saved as Vikunja's HTML. ([#66](https://github.com/rendyhd/vicu/issues/66))
- **Planner: another day.** A block's popover has a Day row: Today, Tomorrow, the next few days, or Pick a date. In Day view, a drag that rests on Back or Forward turns the page, so a block can go to another day in one move, and a row above the timeline shows the day's tasks without a time. ([Vicu-Mobile#101](https://github.com/rendyhd/Vicu-Mobile/issues/101))
- **Open a duplicate.** After Duplicate, the message has Open for a single copy and Undo for any number; Undo deletes every task the duplicate made. ([Vicu-Mobile#97](https://github.com/rendyhd/Vicu-Mobile/issues/97))
- **AppImage updates.** The Linux AppImages carry update information and a `.zsync` file, so AppImageUpdate, Gear Lever, AppImageLauncher, AM and other managers can find and fetch new versions. Pre-releases follow newer pre-releases and the next stable. With thanks to [@Pegoku](https://github.com/Pegoku). ([#64](https://github.com/rendyhd/vicu/issues/64), [#65](https://github.com/rendyhd/vicu/pull/65))

### Fixes

- **Files added offline.** Browse files, a file dropped on a task and an image pasted into the notes now wait in the offline queue when the server cannot be reached, instead of failing, and upload once it is back; images land at the end of the notes. The attachments popover lists waiting and refused uploads with Retry and Remove. ([Vicu-Mobile#104](https://github.com/rendyhd/Vicu-Mobile/issues/104))
- **Space after a link.** A space typed right after a link in the notes was lost. ([#67](https://github.com/rendyhd/vicu/issues/67))
- **Taskbar pin on Windows.** Updating no longer unpins Vicu from the taskbar. A reinstall still goes to the folder of the previous install. ([#69](https://github.com/rendyhd/vicu/issues/69))
- **Typing a time.** Editing the time of a date such as "Today, Oct 8, 1:00 PM" by hand in the When panel no longer clears the date. ([Vicu-Mobile#98](https://github.com/rendyhd/Vicu-Mobile/issues/98))
- **Plan on a Mac with its own region.** Plan crashed on a Mac whose region was chosen apart from its language. Dates now follow that region.
- **Quick Entry.** The text fields no longer draw a heavy blue outline around the whole entry.
- **Times with dots.** Quick add reads "3 p.m." and "9 a.m." as times, as the phone does.
