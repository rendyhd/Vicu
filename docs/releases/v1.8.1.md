# Vicu 1.8.1 — Prerelease

This preview makes task editing smoother and updates the desktop foundation.

### What's new

- Add, edit, and open links directly in task notes, including email links.
- See the correct completion state for subtasks in the expanded task view.
- Run on Electron 44, with compatibility fixes for startup, shortcuts, and packaging across desktop platforms.

This is a prerelease. If you find a rough edge, please [open an issue](https://github.com/rendyhd/Vicu/issues).
