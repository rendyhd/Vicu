# Vicu 1.9.0

Vicu 1.9.0 ships together with Vicu Android 1.9.0. Both apps now read your synced data the same way, the desktop app can be used offline, and a long list of bugs is fixed.

This is a pre-release. It is followed shortly by 1.10.0, which builds on it. If you find a rough edge, please [open an issue](https://github.com/rendyhd/vicu/issues).

### The same data means the same thing on desktop and Android

- Custom lists use the same date windows on both apps, with a new **Include overdue tasks** option for the Today, This week, and This month windows (on by default, as before). Lists also sort the same way, and the editor now offers Completed and Position.
- A due date without a time is stored at the end of that day and shown without a time. A date with a time keeps its time. Older dates saved at midnight show as date-only.
- Today, Upcoming, and Overdue follow your local calendar day, also late in the evening and in time zones far from UTC. Lists move on at midnight by themselves.
- Project review status is calculated the same way on both.
- Quick-add parsing follows one shared set of rules: `!med` and `!critical`, a leading or trailing `!` for today, phrases like `friday 3pm` and `every Monday`. A weekday right before another date stays in the title ("Call Ana about Saturday tomorrow at 3pm" is due tomorrow at 3 PM), and "weekend" and "weekday" are no longer read as dates. A range uses its first date ("Trip friday to sunday" is due Friday), and words about the past ("last friday", "yesterday", "2 days ago") or a date inside another word ("Monday's", "(tomorrow)") are no longer read as dates.

### Your edits no longer overwrite other devices

Vicu now sends only the fields you changed, for tasks and projects. Editing a task on your PC no longer reverts something you changed on your phone a moment earlier.

### Offline editing

- Keep working when the server is unreachable. Creating, editing, completing, and deleting tasks, labels, and pasted images in the main window are queued and sent in order when the connection is back. The last task lists are kept, so the app also starts offline.
- A sync panel in the sidebar shows pending and failed changes, with retry and discard. Changes made for one account are never sent to another.
- Quick Entry and Quick View use the same queue.
- Signing out first tries to send waiting changes and custom lists, and asks before signing out when something has not reached the server yet. Unsynced custom-list edits would be lost; queued task changes stay on the device for your next sign-in to the same account.

### Fixes

- Saving a project review works again on current Vikunja servers.
- A label, project, or priority in the middle of a date no longer makes quick add drop the date: "Call tomorrow @home 3pm" is due tomorrow.
- Quick View loads its lists again instead of showing an error, and reads every page of a long list.
- Today, Anytime, and the other smart lists show every task, not only the first page.
- Accents, emoji, and other non-English characters no longer turn into garbled symbols in long responses.
- The date picker picks the right local day for Today, Tomorrow, and Next week in the evening and at night.
- Reordering in the Inbox and in the project list works when several items share a position.
- The app icon count leaves out tasks of archived projects.
- Logging in or out no longer resets your settings.
- Pasting several lines into a task list creates one task per line, and Quick Entry notes keep their paragraphs.
- Task reminders follow the notification switch and refresh every 15 minutes.
- The update check compares versions correctly and runs every 12 hours.
- Saving a change the server already has (the same title, a task that is already open) no longer shows an error, and such a change can no longer stop the offline queue.
- **File > New Task** opens the new-task composer.
- Opening a task from a reminder or from Quick View brings it up in the main window.
- Quick View refreshes after you change a task's labels, relations, attachments, or project in the main window.
- When creating a task times out, Vicu says the task may already have been created, so you can check before trying again.
- A date like "Oct 9 9am" that is today stays today after 9 AM instead of jumping to next year.
- Custom lists that two devices first synced at the same moment are merged into one, and Quick View no longer reloads its tasks every five minutes.
- The Obsidian link is written to a task only when you save it with the note linked.
- A settings file saved with a byte order mark (for example by Notepad) is read instead of being reset.
- Windows notifications show as Vicu and bring Vicu up when you click them.

### Routine history archive

A routine keeps its last 400 days of history. Older history moves to hidden archive tasks on your Vikunja server (titled "Vicu routine archive", marked done) and stays available in the history view and the CSV export. You may see these tasks in other Vikunja apps; leave them in place.

### Faster

- Today, Upcoming, Tag, and Logbook fetch only what they show, and the Logbook loads older tasks on request.
- Routines and custom lists no longer scan every completed task.
- Quick Entry and Quick View make fewer requests, and the first screen loads a smaller bundle.
- New tasks no longer wait for their position before you can add the next one.

### Security

- Only Vicu's own pages can load in its windows; links open in your browser.
- Attachments from the server are opened safely: programs and scripts are shown in the file manager instead of run, and downloads are size-limited.
- OpenID Connect sign-in checks the state of the redirect, and Settings tells you when saved credentials are not encrypted on this system.
- Upload file names are escaped and the server's file size limit is checked before sending.
- Logging out revokes the backup API token Vicu created for this computer.

### Linux, startup, and browser link

- Launch on startup now works on Linux (an autostart entry for the AppImage).
- New **Start hidden** option opens Vicu in the tray without the main window.
- The browser link no longer needs Node.js: the bridge runs on Vicu's own runtime.

### Under the hood

- Electron 44.5.1.
- The installer packages its resources once instead of twice.
- `VICU_USER_DATA_DIR` runs Vicu with a separate profile folder, handy for testing without touching your own settings.

### Upgrade notes

- Update both apps to 1.9.0.
- Until both apps are updated, an older version may briefly show different custom-list results and can bring back archived routine history entries, which the new version removes again.
- The Windows startup entry is migrated to the new name automatically; there is nothing to do.
